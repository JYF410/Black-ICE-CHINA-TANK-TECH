## 一、最终方案（一句话）

**不自建科技文件夹、不自建标签页**，改为接入黑冰现成的“请求外国装甲科技”机制：

1. 民国玩家打开请求列表时，列表里**用民国替换日本**（列表只有 7 个格子）；
2. 点击民国旗 → 直接获得 `CHI_armor` → 弹出事件提示“保存并重新载入一次”；
3. 载入后科技树按新旗标重建，民国坦克树正常显示；
4. 解锁门槛写在 `flag_click_enabled` 里（国策 + 工业条件）。

## 三、为什么放弃“自建科技文件夹 + 标签页”

尝试过并在 GUI 层做完整套（新建 `trm_armour_chi_folder`、标签页、点击层、36 个 gridbox、年份列、底纹），结果是：

1. **多文件夹同时渲染**：民国树与黑冰原有文件夹叠在同一位置 → 方形小卡片（坦克改装配件）变成 203×84 长方形卡片、图标错乱；
2. **连线消失**：连线由引擎按“单一文件夹”的槽位绘制，叠加渲染时被卡片/背景遮住；
3. `tag CHI`（重新选择国家）能一次性恢复，但这是**引擎级操作**，`on_actions` / scripted GUI / 事件都调不到；`set_cosmetic_tag = CHI` 实测也**不能**触发重建；
4. 因此最终改为“不新建文件夹”，直接复用黑冰的装甲树入口。

## 四、关键结论：科技树 UI 有布局缓存

- 科技树窗口在**首次构建**时确定文件夹、卡片模板与连线；之后改旗标/改数据都不会重绘；
- 只有 **`tag` 重新进入国家上下文** 或 **保存后重新载入** 才会重建；
- 等待游戏日、关窗重开、切标签、切窗口、拖窗口都试过，**均无效**；
- 所以最终在解锁事件里直接告诉玩家“保存并重载一次”，把引擎限制变成明确的操作步骤。

## 五、连线与列距的关系（为什么现在没有连线）

- 科技卡片宽 **203px**（黑冰统一模板），而文件夹列距是 **70px**；
- 相邻卡片重叠 133px，连线整段被压在卡片下面 → 看起来“没有线”；
- 想看到连线必须把列距拉到 **210px（×3）**，代价是树宽约 6600、需要横向滚动；
- 最终作者选择 **保持 70px**（不横向拉宽），接受“看不到连线”，这不是 bug。

## 六、维护指南

### 改解锁条件
只改 `BI_research_tabs_scripted_gui.txt` 第 52~70 行的 `flag_click_enabled`。
- 增删 `has_completed_focus = ...` / `has_tech = ...` 即可；
- 若要“只有民国能点”，可在最外层加 `ROOT = { tag = CHI }`。

### 改列表替换对象
第 ~91 行：
```
remove_from_array = { request_armor_list = JAP }
add_to_array = { request_armor_list = CHI }
```
把 `JAP` 换成你想让位的大国（GER/ITA/JAP/ENG/FRA/USA/SOV）。**列表只有 7 格**（`request_armor_entry` 里 `max_slots_horizontal = 7`），多出来的不会渲染。

### 改解锁提示文字
改 `localisation/{english,simp_chinese}/zz_CHI_armor_unlock_l_*.yml`，保持 **UTF-8 带 BOM**，键名不变。

### 每次改动后
1. 必须**重启游戏**（scripted GUI / 事件 / 本地化只在启动时读取）；
2. 解锁后按提示**保存 → 重载**，科技树才会重建；
3. 若报错，先看 `logs/error.log` 里是否有 `chi_armor_unlock` / `scripted_gui` 相关行。

## 七、如果从备份还原，需要重新确认

1. `history/countries/CHI - China.txt` 是否又出现（出现就会盖掉黑冰历史）；
2. `zz_CHI_startup_country.txt` 是否又送了 `CHI_armor`（会变成开局就有树）；
3. `BI_research_tabs_scripted_gui.txt` 的三处是否还在：门槛、替换、点击给旗标+事件；
4. `countrytechtreeview.gui` 里民国文件夹是否有 36 个 `gridboxtype`；
5. 加载顺序：本 mod 是否仍在播放集靠后位置（若被别的 mod 覆盖同名 `.gui`，整套界面改动都会失效）。

## 八、不要再碰的东西

- 不要给 `trm_armour_chi_folder` 新建标签页/自建入口（会回到多文件夹叠加问题）；
- 不要用 `set_cosmetic_tag` 试图刷新界面（实测无效且有副作用风险）；
- 不要把列距改到 210px 以下又期待看到连线；
- 不要把 `flag_click_enabled` 加回去 `tank_production > 29` 这类原版高门槛除非确实想要。
